# Python Data Visualization Projects

A collection of data visualization applications built using Python, inspired by the *Python Crash Course* book.

## 🚀 Projects Included

1. **Mathematical Plots (`matplotlib`)**: Generated custom line graphs and random walks plotting numerical data variations.
2. **Global Weather Variations (`csv` & `json`)**: Parsed global weather datasets to track high/low temperatures over time and mapped global earthquake data chronologically.
3. **Live GitHub API Explorer (`requests` & `pygal`)**: Designed an interactive dashboard that polls GitHub's live API to isolate and visualize the most-starred Python repositories dynamically.

## 🛠️ Tech Stack
* Python 3
* Matplotlib
* Pygal (with `pygal_maps_world`)
* Requests API Client
